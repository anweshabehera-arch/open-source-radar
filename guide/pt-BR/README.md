# O Guia de Contribuição Open Source

Um caminho prático de "quero contribuir" até "meu pull request foi aceito", escrito para quem está fazendo isso pela primeira vez e útil para todo mundo depois disso.

Leia em ordem na primeira vez. Cada capítulo termina com uma lista de verificação curta à qual você pode voltar depois.

[Versão em inglês](../README.md) · Capítulos 1 a 6 traduzidos para o português; os demais capítulos estão em inglês por enquanto.
